NARASI: Panduan Coba untuk Juri
================================

Server NARASI sudah jalan online, jadi kamu nggak perlu instal apa-apa selain ekstensi browser.
Total waktunya sekitar 2 menit.


1. Buka dashboard petugas (Penerangan TNI AD)
---------------------------------------------
Klik atau salin link ini ke Chrome/Edge:

    {{DASHBOARD_URL}}

Link ini sudah termasuk token akses, jadi langsung masuk tanpa login.
Simpan baik-baik ya, jangan disebar.


2. Pasang ekstensi (cukup sekali)
---------------------------------
1. Ekstrak file zip ini (klik kanan > Extract All).
2. Buka Chrome, ketik  chrome://extensions  di kolom alamat
   (di Edge:  edge://extensions ).
3. Nyalakan "Developer mode" di pojok kanan atas.
4. Klik "Load unpacked", lalu pilih folder  ekstensi-NARASI  hasil ekstrak tadi.
5. Klik ikon puzzle di toolbar, lalu pin NARASI biar gampang diakses.


3. Coba langsung
----------------
Buka video pendek di Instagram Reels, TikTok, YouTube Shorts, atau Facebook Reels.
Saat video diputar, label NARASI muncul di atas caption. Klik labelnya untuk melihat
klaim yang ditemukan, sumber bukti, dan kesimpulannya.

Video contoh yang pasti memunculkan label:
  - YouTube Shorts: (isi tautan)
  - TikTok:         (isi tautan)
  - Instagram:      (isi tautan)

Lalu lihat dashboard dari langkah 1: video yang barusan kamu tonton ikut muncul
di tab Realtime, dan kalau kamu menekan "Laporkan ke TNI AD" di panel ekstensi,
laporannya masuk ke tab Laporan.


Kalau ada kendala
-----------------
- Label tidak muncul: refresh halaman videonya sekali, lalu pastikan NARASI aktif
  (klik ikon NARASI di toolbar).
- Dashboard minta token: buka lagi link di langkah 1 persis seperti tertulis.
- Cek apakah server hidup: buka  {{SERVER_URL}}/health

Data di dashboard sebagian adalah lalu lintas simulasi supaya grafiknya terisi;
hasil cek dari video yang kamu tonton sendiri adalah hasil analisis sungguhan.
